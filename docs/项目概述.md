# MEMEFinder 项目概述

## 1. 项目简介

MEMEFinder 是一个本地表情包查找器，旨在帮助用户通过文字搜索快速找到本地存储的表情包。它利用 OCR（光学字符识别）技术提取图片中的文字，并结合情绪分析功能，实现智能化的表情包管理和检索。

**核心功能：**
*   **本地图源管理**：支持添加多个本地文件夹作为表情包来源。
*   **智能 OCR 识别**：自动扫描并识别图片中的文字内容（基于 RapidOCR）。
*   **情绪分析**：对识别到的文字进行情绪分析（正向/负向/中性），辅助搜索。
*   **快速搜索**：支持关键词搜索和情绪筛选。
*   **隐私安全**：所有处理均在本地完成，无需联网上传图片。

## 2. 技术栈

*   **编程语言**: Python 3
*   **GUI 框架**: Tkinter (Python 内置)
*   **数据库**: SQLite 3
*   **OCR 引擎**: RapidOCR (基于 ONNXRuntime)
*   **情绪分析**: SnowNLP (中文) / TextBlob (英文)
*   **打包工具**: PyInstaller

## 4. 模块功能详解

### 4.1 核心模块 (`src/core`)

负责应用程序的主要业务逻辑，包括数据存储、图像处理和算法分析。

*   **`database.py` (数据库管理)**
    *   管理 SQLite 数据库连接池。
    *   定义数据表结构：
        *   `image_sources`: 存储图源文件夹路径及扫描状态。
        *   `images`: 存储图片信息、OCR 识别结果、情绪分析结果。
        *   `app_state`: 存储应用配置和断点续传状态。
    *   提供增删改查接口，支持批量操作以优化性能。

*   **`ocr_engine.py` (OCR 引擎)**
    *   封装 `RapidOCR` 库。
    *   支持 GPU 加速（自动检测 CUDA/DirectML）和 CPU 模式回退。
    *   提供图片文本检测和识别功能。
    *   包含图像预处理（如 Padding）以提高边缘文字识别率。

*   **`emotion_analyzer.py` (情绪分析)**
    *   提供文本情绪倾向分析。
    *   **多引擎支持**：
        *   `SnowNLP`: 针对中文文本的情绪分析（默认）。
        *   `TextBlob`: 针对英文文本的情绪分析。
        *   `Keyword`: 基于关键词库的简单规则匹配（作为回退方案）。
    *   输出情绪类别（正向/负向/中性）及置信度分数。

*   **`ocr_processor.py` (OCR 处理器)**
    *   整合 OCR 引擎和情绪分析器。
    *   实现完整的图片处理流水线：读取图片 -> OCR 识别 -> 文本提取 -> 文本过滤 -> 情绪分析。
    *   包含文本清洗功能（去除水印、网址、特殊符号）。
    *   集成资源监控，定期执行垃圾回收。

*   **`scanner.py` (文件扫描)**
    *   扫描指定目录下的图片文件。
    *   计算文件哈希值，避免重复处理。

### 4.2 界面模块 (`src/gui`)

基于 Tkinter 构建的用户界面，采用模块化设计。

*   **`main_window.py` (主窗口)**
    *   应用程序的主框架。
    *   管理标签页切换和全局状态。
    *   处理断点续传逻辑。

*   **`source_tab.py` (图源管理页)**
    *   展示和管理图片来源文件夹。
    *   提供添加、删除、启用/禁用图源的功能。
    *   显示各图源的图片数量和扫描状态。

*   **`process_tab.py` (图片处理页)**
    *   控制图片扫描和 OCR 处理任务。
    *   显示实时处理进度、日志和资源使用情况（CPU/内存）。
    *   支持暂停、恢复和停止处理。

*   **`search_tab.py` (图片搜索页)**
    *   提供搜索界面：关键词输入框、情绪筛选下拉框。
    *   以瀑布流或网格形式展示搜索结果。
    *   支持预览大图、复制图片、打开文件位置等操作。
    *   实现分页加载，优化大量图片展示时的性能。

*   **`loading_window.py` (加载窗口)**
    *   程序启动时的初始化界面。
    *   负责后台加载模型文件，避免界面卡顿。

### 4.3 工具模块 (`src/utils`)

*   **`logger.py`**: 统一的日志记录配置。
*   **`gpu_detector.py`**: 检测系统 GPU 硬件和驱动状态。
*   **`resource_monitor.py`**: 监控系统内存和 CPU 使用率。
*   **`model_mover.py`**: 处理模型文件的移动和部署。

## 5. 数据流程

1.  **添加图源**: 用户在 GUI 添加文件夹 -> `scanner` 扫描文件 -> 存入 `image_sources` 和 `images` 表（状态为未处理）。
2.  **处理图片**: 用户点击开始处理 -> `ocr_processor` 读取未处理图片 -> 调用 `ocr_engine` 识别文字 -> 调用 `emotion_analyzer` 分析情绪 -> 更新 `images` 表（写入结果，标记为已处理）。
3.  **搜索图片**: 用户输入关键词 -> `database` 查询 `images` 表（匹配 `ocr_text` 或 `filtered_text`） -> GUI 展示结果。
