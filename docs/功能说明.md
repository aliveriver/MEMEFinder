## 基础功能

### 图源管理
在「图源管理」标签页中管理表情包来源文件夹。

**功能：**
- ➕ **添加图源**：选择包含表情包的文件夹
- 🗑️ **删除图源**：移除图源及其所有图片记录
- ✅ **启用/禁用**：临时禁用某个图源，不删除数据
- 🔄 **扫描新图片**：增量扫描，自动 MD5 去重
- 📊 **显示信息**：添加时间、最后扫描时间、图片数量

### OCR 识别
在「图片处理」标签页中处理图片。

**功能：**
- 🔍 **文字识别**：使用 RapidOCR 提取图片中的文字
- 😊 **情感分析**：分析文字情感（正向/负向/中性）
- ⏸️ **暂停/继续**：随时暂停和继续处理
- 🛑 **停止任务**：终止当前处理任务
- 📊 **实时进度**：显示处理进度和剩余时间
- 🎮 **GPU 加速**：支持 CUDA 加速（如果可用）

## 标签系统

### 创建标签
1. 在搜索页面顶部点击「🔖 管理标签」按钮
2. 在标签管理器中点击「➕ 新建标签」
3. 输入标签名称
4. 点击颜色按钮选择背景色
5. 点击「保存」

**标签特性：**
- 🎨 **自定义颜色**：16种预设颜色 + 自定义颜色选择器
- 📝 **唯一名称**：标签名称不能重复
- 🔤 **自动对比色**：根据背景色自动计算文字颜色（黑/白）
- 📊 **使用统计**：显示每个标签关联的图片数量

### 编辑标签
1. 在标签管理器中选择要编辑的标签
2. 点击「✏️ 编辑标签」
3. 修改名称或颜色
4. 点击「保存」

### 删除标签
1. 在标签管理器中选择要删除的标签
2. 点击「🗑️ 删除标签」
3. 确认删除

**注意**：删除标签会解除所有图片与该标签的关联。

### 为图片添加标签

#### 方法1：详情面板
1. 点击图片查看详情
2. 在详情面板找到「标签」区域
3. 点击「➕」按钮
4. 在标签选择器中勾选要添加的标签
5. 点击「确定」

#### 方法2：批量编辑
1. 多选图片（复选框/Ctrl+点击/Shift+点击）
2. 右键点击选中的图片
3. 选择「🏷️ 编辑标签」
4. 选择操作模式和标签
5. 点击「💾 应用」

### 标签筛选
1. 在搜索条件区找到「标签」下拉菜单
2. 勾选要筛选的标签（支持多选）
3. 自动显示包含所选标签的图片

## 批量操作

### 使用右键菜单
1. 选择多张图片
2. 右键点击选中的图片
3. 选择要执行的操作

### 批量收藏
**适用场景**：标记多张常用表情包

**操作步骤**：
1. 多选图片
2. 右键 → 「❤ 收藏」

**智能显示**：
- 只有未收藏图片 → 显示「❤ 收藏」
- 只有已收藏图片 → 显示「💔 取消收藏」
- 混合状态 → 同时显示两个按钮

### 批量编辑标签
**适用场景**：为多张图片统一分类

**操作步骤**：
1. 多选图片
2. 右键 → 「🏷️ 编辑标签」
3. 选择操作模式：
   - **添加标签**：保留原有标签，添加选中的标签
   - **移除标签**：只移除选中的标签，保留其他标签
   - **替换标签**：清空原有标签，设置为选中的标签
4. 勾选标签
5. 点击「💾 应用」

**快捷操作**：
- 点击「🔖 管理标签」可快速创建新标签
- 点击「全选」/「全不选」快速选择
- 关闭对话框后标签列表自动刷新

### 批量编辑情感
**适用场景**：统一设置情感标签

**操作步骤**：
1. 多选图片
2. 右键 → 「😊 编辑情感」
3. 选择情感：正向/负向/中性/未分类
4. 点击「💾 应用」

### 批量转移到图源
**适用场景**：整理图片，将图片移动到指定文件夹

**操作步骤**：
1. 多选图片
2. 右键 → 「📁 转移到图源」
3. 选择目标图源
4. 确认转移

**注意事项**：
- 图片文件会被移动到目标文件夹
- 数据库记录会自动更新
- 如果目标文件夹已存在同名文件，会自动重命名

### 批量删除
**适用场景**：清理不需要的图片

**操作步骤**：
1. 多选图片
2. 右键 → 「🗑️ 删除」
3. 二次确认
4. 从磁盘和数据库删除

**⚠️ 警告**：此操作不可恢复！图片将被永久删除。

## 以图搜图

MEMEFinder 支持强大的以图搜图功能，基于深度学习和感知哈希的混合相似度算法。

### 使用以图搜图

#### 方法1：选择本地图片
1. 点击搜索工具栏的「📷 以图搜图」按钮
2. 选择「选择本地图片」
3. 从文件系统中选择参考图片
4. 系统自动计算相似度并排序显示

#### 方法2：粘贴图片
1. 截图或复制图片到剪贴板
2. 点击「📷 以图搜图」→「粘贴图片」
3. 系统自动使用剪贴板图片进行搜索

#### 方法3：使用当前选中图片
1. 在搜索结果中选中一张图片
2. 点击「📷 以图搜图」→「使用当前选中图片」
3. 找到与选中图片相似的其他图片

### 以图搜图设置

点击「⚙️ 以图搜图设置」可以调整搜索参数：

#### 相似度算法权重
- **深度学习权重**（0.0-1.0）：基于 MobileNetV3 的图像特征相似度
- **PHash 权重**（0.0-1.0）：基于感知哈希的相似度
- 权重总和应为 1.0，系统会自动调整

**推荐配置**：
- 通用场景：深度学习 0.8，PHash 0.2（默认）
- 精确匹配：深度学习 0.5，PHash 0.5
- 语义相似：深度学习 1.0，PHash 0.0

#### 相似度阈值
- **最小相似度**（0.0-1.0）：低于此值的图片不显示
- 默认 0.0，显示所有结果
- 建议设置 0.3-0.5 过滤不相关图片

#### 比较数量限制
- **最大比较数量**：限制参与比较的图片数量
- 留空则比较所有图片
- 图片数量较多时可设置限制提升速度

### 取消以图搜图
点击「❌ 取消以图搜图」恢复正常搜索模式。

## 智能排序

MEMEFinder 提供多种智能排序方式，帮助您更好地浏览图片。

### 排序方式

在搜索工具栏的「排序」下拉菜单中选择：

#### 无排序（默认）
按数据库顺序显示图片。

#### 深度学习相似度排序
- 基于 MobileNetV3 提取的图像特征
- 智能语义相似度计算
- 适合找相似构图、相似主题的图片

**使用方法**：
1. 选择「深度学习相似度排序」
2. 选择一张参考图片
3. 图片按相似度从高到低排列

#### PHash 相似度排序
- 基于感知哈希算法
- 对旋转、缩放、轻微变形鲁棒
- 适合找几乎相同或略有差异的图片

**使用方法**：
1. 选择「PHash 相似度排序」
2. 选择一张参考图片
3. 图片按相似度从高到低排列

#### 混合相似度排序
- 结合深度学习和 PHash 两种算法
- 权重可在「以图搜图设置」中调整
- 最全面的相似度评估

**使用方法**：
1. 选择「混合相似度排序」
2. （可选）在设置中调整权重
3. 选择一张参考图片
4. 图片按综合相似度排列

#### RGB 颜色排序
- 按图片主色调分组排序
- 自动识别红、橙、黄、绿、青、蓝、紫、粉、棕、黑、白、灰
- 适合按颜色浏览图片

**使用方法**：
1. 选择「RGB 颜色排序」
2. （可选）选择参考图片，优先显示相似颜色
3. 图片按主色调分组显示

### 取消排序
在下拉菜单中选择「无排序」恢复默认顺序。

## 搜索与筛选

### 关键词搜索
1. 在搜索框输入关键词
2. 按回车或点击「搜索」
3. 搜索 OCR 识别的文本内容

**提示**：支持部分匹配，不区分大小写

### 情感筛选
1. 点击「情感」下拉菜单
2. 勾选要筛选的情感（可多选）：
   - 😊 正向
   - 😢 负向
   - 😐 中性
   - ❓ 未分类
3. 自动筛选显示

### 图源筛选
1. 点击「图源」下拉菜单
2. 勾选要筛选的图源（可多选）
3. 只显示选中图源的图片

### 标签筛选
1. 点击「标签」下拉菜单
2. 勾选要筛选的标签（可多选）
3. 显示包含所选标签的图片

### 收藏筛选
1. 勾选「❤ 只看收藏」
2. 只显示已收藏的图片

### 组合筛选
- 可以同时使用多个筛选条件
- 条件之间是「与」的关系
- 例如：关键词「新年」+ 情感「正向」+ 标签「节日」

### 分页控制
1. 设置每页显示数量：10/20/50/100
2. 使用「上一页」/「下一页」按钮翻页
3. 直接输入页码跳转

## 常见问题

### Q: 标签和收藏有什么区别？
**A**: 
- **标签**：多对多关系，一张图片可以有多个标签，用于分类管理
- **收藏**：标记常用图片，快速筛选

### Q: 批量操作后详情面板没更新？
**A**: 已修复，现在批量操作后详情面板会自动刷新。如果仍有问题，请重启程序。

### Q: 如何快速选择大量图片？
**A**: 
1. 点击第一张图片
2. 按住 Shift 键
3. 点击最后一张图片
4. 范围内所有图片都会被选中

### Q: 删除标签会删除图片吗？
**A**: 不会。删除标签只是解除图片与标签的关联，不会删除图片本身。

### Q: 转移图源后原文件还在吗？
**A**: 不在。转移操作会将文件移动到目标文件夹，原位置的文件会被删除。
